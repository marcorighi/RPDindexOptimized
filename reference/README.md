# Reference implementation snapshot

`computeindex_reference.py` is an archival copy of the historical `computeindex.py` used only as a regression-test baseline for `RPDindexOptimized`.

Authoritative historical references:

- GitHub: https://github.com/marcorighi/RPDindex
- Zenodo DOI: https://doi.org/10.5281/zenodo.20313771

The reference file in this directory should not be modified when developing or benchmarking the optimized implementation. If the baseline is ever changed, record the exact source release/tag/commit and update the validation documentation.
